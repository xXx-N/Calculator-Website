# Simple Calculator

A clean, lightweight, and responsive calculator built with HTML, CSS, and TypeScript.

## Features
- Basic arithmetic operations (`+`, `-`, `*`, `/`)
- Keyboard support (`0-9`, operators, `Enter`, `Backspace`, `Escape`)
- Protection against consecutive operators and division by zero
- Responsive design with smooth button animations

## Project Structure
- `index.html` — Markup and layout
- `style.css` — Styling and grid layout
- `script.ts` — TypeScript source code
- `script.js` — Compiled JavaScript for the browser
- `tsconfig.json` — TypeScript configuration

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser.
